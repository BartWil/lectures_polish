# Obrazy i atrybucje

W tym katalogu przechowuj wyłącznie obrazy wykorzystywane na opublikowanej stronie.

Przed dodaniem obrazu uzupełnij odpowiadający mu wpis w `atrybucje.yml`. Każdy wpis musi zawierać nazwę pliku, autora lub instytucję, adres źródłowy, licencję oraz informację, czy obraz zmodyfikowano.
