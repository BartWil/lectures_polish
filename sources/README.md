# Materiały źródłowe

Katalog `sources/` służy wyłącznie do przechowywania oryginalnych materiałów roboczych. Nie jest źródłem treści publikowanej automatycznie.

- `pptx/` — prezentacje źródłowe.
- `docx/` — dokumenty źródłowe.

Po uzyskaniu wyraźnego polecenia można użyć skryptów z `scripts/`, aby przygotować z nich szkice materiałów `.qmd`. Każdy szkic wymaga następnie redakcji merytorycznej i sprawdzenia praw do wykorzystania obrazów.
